# Предразметка для CVAT

Пайплайн закрывает рутину «с нуля»: модель находит игроков и диск, ByteTrack
даёт треки, вы вручную раскладываете игроков по командам, а на выходе
получается `annotations.xml` формата **CVAT for video 1.1**. В CVAT остаётся
поправить рамки/IDs и, если нужно, команды.

```
видео → YOLO + ByteTrack → tracks.json
      → ручная разметка команд (браузер) → teams.json
      → annotations.xml → CVAT
      → экспорт из CVAT → import-cvat → cvat_tracks.json / teams_from_cvat.json
```

## 1. Извлечь треки

```bash
uv run python -m ultitrack.cvat extract data/raw/r1.mp4
```

По умолчанию результаты лежат в `data/cvat/r1/`:

- `tracks.json` — все игроки и диск по кадрам (0-based), с ID ByteTrack;
- дальше `label`/`export` читают этот файл.

Полезные флаги:

| Флаг | Смысл |
| --- | --- |
| `--conf 0.15` | порог детекции игроков |
| `--disc-conf 0.22` | порог детекции диска |
| `--field-margin 1.0` | допуск фильтра поля в метрах |
| `--no-field-filter` | не отбрасывать людей/диски вне поля |
| `--min-track-frames 3` | выбросить короткие ложные треки |
| `--max-frames 300` | быстрый тест на первых кадрах |
| `--force` | перезаписать `tracks.json` |

Фильтр поля использует `calib/homography.json`. Если разрешение видео не
совпадает с калибровкой (сейчас 1920×1080), гомография не загрузится, и
фильтр автоматически отключится — лучше снять заново или запустить с
`--no-field-filter`.

## 2. Разметить команды руками

```bash
uv run python -m ultitrack.cvat label data/raw/r1.mp4
```

Откроется локальный интерфейс (`http://127.0.0.1:8766/`):

- клик по рамке: `? → A → B → ?`;
- кнопки `A` / `B` / `?` в списке треков справа;
- `×` (или клавиша `X`) — исключить трек из XML: судья, запасной, ложный бокс;
- `A` / `B` / `U` — поставить команду выбранному треку;
- `←` / `→` — кадры, `Shift` — по 10; `J` — следующий неразмеченный;
- колесо — зум, перетаскивание — панорама;
- **Авто по цвету** — достроить команды для неразмеченных треков по цвету
  формы (нужны эталоны хотя бы одной ручной пары A и B);
- **Swap A/B** — поменять команды местами;
- **Сохранить XML** — записать `annotations.xml`.

Изменения сразу пишутся в `data/cvat/r1/teams.json`, поэтому браузер можно
закрыть и вернуться позже.

Если размечать команды в браузере не хочется, можно сразу собрать XML с
`team=unknown` и проставить команды в CVAT:

```bash
uv run python -m ultitrack.cvat export data/raw/r1.mp4
```

Но тогда придётся вручную поставить атрибут у каждого трека в CVAT; клики в
браузере обычно быстрее.

В `data/cvat/r1/` появятся:

- `annotations.xml` — файл для импорта в CVAT;
- `tracks.csv` — сводка по трекам (команда, кадры, уверенность);
- `cvat_labels.json` — шпаргалка по меткам/атрибутам;
- `teams.json` — привязки трек → команда.

## 3. Загрузить в CVAT

1. Создайте **video task** (не image task) из исходного видео.
2. Создайте метки:

   | Label | Тип | Атрибут |
   | --- | --- | --- |
   | `player` | rectangle | `team`: select, значения `A`, `B`, `unknown`, default `unknown`, **mutable = off** |
   | `disc` | rectangle | без атрибутов |

   Если в вашем таске метки называются иначе, передайте их в
   `label`/`export`: `--player-label person --disc-label frisbee --team-attr team`.
3. В задаче: **Actions → Upload annotations → CVAT for video 1.1** и выберите
   `annotations.xml`.
4. Проверьте: рамки интерполированы, у каждого трека игрока стоит `team`.
   Правьте рамки, IDs, команды; при необходимости split/merge треков.

> CVAT импортирует только те атрибуты, которые уже созданы в метке. Если
> `team` не добавить в `player`, импорт атрибута будет проигнорирован или
> завершится ошибкой.

## 4. Забрать исправления обратно

После правок в CVAT: **Actions → Export task dataset → CVAT for video 1.1**.
Затем:

```bash
uv run python -m ultitrack.cvat import-cvat annotations.xml \
  --out-dir data/cvat/r1 --per-frame
```

Если метка игрока в CVAT называется не `player`, добавьте
`--player-label person` (и `--team-attr`, если атрибут назван иначе).

Получатся:

- `cvat_tracks.json` — треки и рамки после правок (с `--per-frame` — покадрово
  с линейной интерполяцией);
- `cvat_tracks.csv` — сводка;
- `teams_from_cvat.json` — команды в формате `teams.json`; его можно передать
  в `export --teams ...`, если вы пересобираете XML без UI.

## Пакетная обработка

Экстракция неинтерактивная, её можно запустить сразу для всех роликов:

```bash
for video in data/raw/*.mp4; do
  uv run python -m ultitrack.cvat extract "$video"
done
```

Дальше для каждого ролика:

```bash
uv run python -m ultitrack.cvat label data/raw/r1.mp4
```

`label` можно запускать заново: `tracks.json` и `teams.json` переиспользуются.

## Ограничения и нюансы

- **Только video-таски CVAT.** Для image-тасков нужен другой формат; этот
  пайплайн пишет interpolation-треки.
- **Команда — свойство трека.** Если ByteTrack перепутал игроков внутри
  одного ID, в CVAT трек надо разделить; после этого команду придётся
  поставить заново.
- **Диск — один трек на ролик.** Модель может не видеть диск несколько
  секунд; в XML это дырки (`outside="1"`), их видно и можно поправить.
- **A/B условны.** Автокластеризация не знает, кто «синие»; если кластеры
  поменялись местами, нажмите **Swap A/B**.
- **Судьи и запасные.** Фильтр поля убирает часть бровки, но не всех.
  Исключайте лишние треки кнопкой `×`, иначе они попадут в CVAT.
- **Трек короче 3 кадров** по умолчанию выбрасывается; для коротких
  перебежек уменьшите `--min-track-frames`.
- **Модель кого-то не нашла** — добавьте рамку прямо в CVAT. Пайплайн не
  создаёт новые объекты, он только предзаполняет существующие.
- **Повторный `extract --force` меняет ID треков.** После него `teams.json`
  может ссылаться на старые ID; интерфейс предупредит. Лучше не пересобирать
  треки после ручной разметки команд.

## Формат `tracks.json`

```jsonc
{
  "schema_version": 1,
  "meta": {
    "video": "/abs/path/r1.mp4",
    "video_name": "r1.mp4",
    "width": 1920,
    "height": 1080,
    "fps": 30.0,
    "total_frames": 862,
    "conf": 0.15,
    "disc_conf": 0.22
  },
  "tracks": [
    {
      "id": 1,                 // ID для CVAT (диск — 0)
      "label": "player",
      "source_id": 42,         // ID ByteTrack
      "team": "A",
      "team_conf": 1.0,
      "team_source": "manual",
      "excluded": false,
      "frames": {
        "0": [787.53, 367.13, 864.79, 578.78, 0.94]
      }
    }
  ]
}
```

`frames` — `frame → [x1, y1, x2, y2, confidence]`, кадры с нуля.
